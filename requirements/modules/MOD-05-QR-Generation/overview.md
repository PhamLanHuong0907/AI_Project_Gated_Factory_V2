# MOD-05: QR Code Generation - Overview

## Module Identity

| Field | Value |
|-------|-------|
| Module ID | MOD-05 |
| Module Name | QR Code Generation |
| Requirement Reference | REQ-05 |
| Status | SPECIFIED |

## Purpose

Generate QR codes for attendance scanning. QR codes can be generated per employee, per shift, or per day based on configuration.

## Actors

| Actor | Role | Access Level |
|-------|------|--------------|
| Employee (ACT-01) | Generate own QR code | Button to generate, view own QR code |
| System (ACT-SYS) | Auto reminders, validity check | Send reminders, validate QR codes |
| Administrator (ACT-02) | Override/invalidate | View all QR codes, invalidate |

## QR Code Types

| Type | Description | Validity | Use Case |
|------|-------------|----------|----------|
| Per Employee | Unique per employee | Configurable | Employee-specific QR |
| Per Shift | Changes each shift | Shift duration | Shift-based attendance |
| Per Day | Changes daily | 24 hours | Daily attendance |
| On-Demand | Generated when requested | Short-term | Ad-hoc attendance |

## Constraints

1. QR codes must be unique per generation
2. QR codes must have validity period based on configuration
3. QR codes must be generated by employee pressing button
4. QR codes must be traceable
5. System must remind employees if near work time without QR

## Assumptions

1. Employees generate their own QR codes by pressing button
2. QR codes are stored in database
3. QR codes can be displayed on screen
4. QR validity period is configured by admin
5. System sends reminders when approaching work time
