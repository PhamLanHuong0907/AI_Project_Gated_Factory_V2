# Design System Template

## Global App Shell — locked
Define one product identity, sidebar, header, content container, breadcrumb, menu hierarchy, active state, responsive behavior, and permission behavior. Module prompts may change only active item, expanded state, and page content.

## Tokens
Define semantic colors, typography, spacing, radius, border, shadow, density, breakpoints, focus, disabled, success, warning, danger, and information states.

## Shared components
Define buttons, inputs, select, table, pagination, cards, tabs, modal, drawer, toast, alert, loading, empty, error, and access-denied patterns.

## Master visual references
The approved Login, representative List, and representative Create/Edit screens establish the reusable visual language.
