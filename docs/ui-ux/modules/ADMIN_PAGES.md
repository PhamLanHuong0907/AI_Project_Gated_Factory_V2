
### Countdown Timer

| State | Display | Color |
|-------|---------|-------|
| > 50% | "⏱️ MM:SS còn lại" | Green `#16A34A` |
| 20-50% | "⏱️ MM:SS còn lại" | Yellow `#D97706` |
| < 20% | "⏱️ MM:SS còn lại" | Red `#DC2626` |
| Expired | "Mã đã hết hạn" | Red badge |

### QR Code States

| State | Appearance | Action |
|-------|------------|--------|
| WAITING | Spinner, grayed out | — |
| ACTIVE | Full color, countdown running | Auto-refresh on expiry |
| EXPIRED | Opacity 0.5, red badge | "Tạo mã mới" button |
