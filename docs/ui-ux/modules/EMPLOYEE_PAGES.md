### Chi tiết lương breakdown

| Component | Formula | Example |
|-----------|---------|---------|
| Lương cơ bản | `base_salary` | 8,000,000 |
| + Kinh nghiệm | `base_salary × percent_increase / 100` | +800,000 (10%) |
| + Thưởng | `SUM(bonus.amount)` | +2,000,000 |
| - Phạt | `SUM(penalty.amount)` | -50,000 |
| = Thực nhận | `total` | 10,750,000 |
